An interactive **cursor-controlled light effect** built using HTML, CSS, and JavaScript, where a moving torch reveals parts of a dark background in real time.

This project is part of **_When Things Responded_** — a reflection-driven frontend series focused on making interfaces react dynamically to user movement and interaction.

---

## 🚀 Project Overview

Reflection-008 creates a cinematic **torchlight effect** that follows the user’s mouse movement across the screen.

The experience includes:

- 🖱️ Real-time mouse tracking
- 🔦 Dynamic radial light effect
- 🎮 Custom animated torch cursor
- 🌑 Dark overlay with illuminated focus area

The goal of this reflection is to explore:

- CSS variables updated through JavaScript
- Mouse event tracking
- Radial gradient manipulation
- Custom cursor implementation
- Immersive visual effects using pure frontend tools

## 📌 Core Concepts Implemented

### 1️⃣ Mouse Position Tracking

The application listens to global mouse movement events and captures the X and Y coordinates in real time.

These coordinates dynamically update the visual light source on the screen.

This demonstrates responsive UI behavior based on continuous input.

---

### 2️⃣ CSS Variable Manipulation

Mouse coordinates are injected into CSS custom properties.

The radial gradient uses these variables to reposition the light source dynamically.

This shows how JavaScript can control CSS styling efficiently.

---

### 3️⃣ Radial Gradient Light Mask

A full-screen dark overlay is applied using a radial gradient.

The center of the gradient is transparent while the outer region remains dark, creating a spotlight illusion.

This reinforces advanced CSS gradient usage for visual effects.

---

### 4️⃣ Custom Cursor Implementation

The default cursor is hidden and replaced with an animated torch image.

The torch follows the mouse movement and rotates slightly to enhance realism.

This demonstrates custom cursor techniques in web design.

---

### 5️⃣ Immersive UI Experience

The full-screen background combined with a controlled light focus creates:

- Game-like atmosphere
- Cinematic feel
- Interactive storytelling potential

This expands beyond traditional UI into experience-based design.
