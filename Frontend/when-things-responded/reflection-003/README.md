# 🏏 Guess the Winner — reflection-003

A fun, interactive **JavaScript guessing game** that demonstrates how **user input**, **random logic**, and **UI state changes** work together to create engaging experiences.
This project is part of **_When Things Responded_**, a reflection-based frontend series focused on observing how **interfaces react dynamically** to user actions.

---

## 🚀 Project Overview

**Guess the Winner** is a simple game where the user enters a **lucky number** and clicks **Start**. On each click, a random team from the **ICC Men’s T20 World Cup** list is displayed. When the number of clicks matches the user’s chosen number, the current team is declared as the **winner**.

The project focuses on understanding:

- User-driven state progression
- Random data selection
- Conditional UI updates
- Visual feedback through styling changes

---

## 🛠️ Technologies Used

- **HTML5** — structure and input handling
- **CSS3** — layout, transitions, and visual feedback
- **JavaScript (Vanilla JS)** — logic, state tracking, DOM updates
- **Git & GitHub** — version control

---

## ✨ Key Features

- User-controlled guessing using a numeric input
- Random team selection on each interaction
- Dynamic update of team name, flag, and trophies
- Background color changes based on selected team
- Winner announcement when guess condition is met
- Smooth transitions and animated UI feedback

---

## 📌 Core Concepts Implemented

### 🧱 1. HTML Structure

- Numeric input for user guesses
- Button to trigger game logic
- Dedicated UI area for displaying team details
- Semantic structure for readability and clarity

---

### 🎨 2. CSS Styling & Visual Feedback

- Flexbox-based centered layout
- Dynamic background color transitions
- Animated button interactions
- Highlighted winner state using text effects

CSS is used not just for layout, but as **feedback for game state changes**.

---

### 🧠 3. JavaScript Logic & State Handling

- Teams stored as objects inside an array
- Random index generation using `Math.random()`
- User input validated before execution
- Click count tracked to match user guess

This reinforces thinking in terms of **state progression over time**.

---

### 🖱️ 4. DOM Manipulation & Events

- Elements accessed using `querySelector()`
- `click` events trigger random selection and UI updates
- DOM updated dynamically with text, images, and styles
- Conditional rendering for the winner announcement

Each interaction clearly demonstrates **cause → effect** in the UI.
