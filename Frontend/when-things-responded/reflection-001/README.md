A simple frontend project demonstrating how to create a **custom file upload button** using **HTML, CSS, and JavaScript**.  
This project is part of **_When Things Responded_**, a series focused on understanding how user interactions trigger UI responses on the web.

---

## 🚀 Project Overview

This project replaces the default browser file input UI with a **custom-styled upload button**.  
When the user clicks the button, it programmatically opens the file selector. After a file is selected, the button dynamically updates to display the selected file name.

The goal of this project is to understand **event-driven UI behavior**, **DOM manipulation**, and **interactive response handling** using **vanilla JavaScript**.

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)

---

## ✨ Key Features

- Custom-designed file upload button
- Native file input hidden for better UI control
- Button click triggers file selector
- Selected file name displayed dynamically
- Clean and beginner-friendly codebase

---

## 📌 Core Concepts Implemented & Analyzed

### 🧱 1. HTML Structure

- Uses native `<input type="file">`
- Input element hidden to allow full UI customization
- Button acts as the interactive surface

---

## 🎨 2. CSS Styling & Layout

- Centered layout implemented using **Flexbox**
- Custom button styling for better UI control
- Default browser file input hidden using CSS for a cleaner interface

---

## 🖱️ 3. JavaScript DOM Manipulation

- Elements are selected using `querySelector`
- Button click programmatically triggers the hidden file input
- Demonstrates a clear **UI → response** relationship between user action and interface behavior

---

## 📂 4. Event Handling & UI Feedback

- `change` event listens for file selection
- Selected file accessed using `e.target.files`
- Button text dynamically updates to reflect user action

This approach provides **immediate visual feedback**, improving the overall user experience.
