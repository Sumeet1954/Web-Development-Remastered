# 📁 Chapter 1 — Portfolio Hub (The Surface)

This directory contains the **Live Index** for all projects completed in  
**Chapter 1: The Surface** of the Web Development Remastered journey.

It provides a single place to access every deployed incident from this chapter.

---

## 📌 Overview

The Portfolio Hub is:

- A **responsive project gallery**
- Built with **HTML, CSS Grid, and Vanilla JavaScript**
- Dynamically rendered from a single data array
- Easily expandable without layout changes

No project cards are hardcoded into the HTML.

---

## 🛠️ Tech Stack

- HTML5  
- CSS3 (Responsive Grid Layout)  
- JavaScript (Dynamic Rendering)  
- GitHub Pages (Deployment)
