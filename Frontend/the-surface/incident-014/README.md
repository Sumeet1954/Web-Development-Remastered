# 🚗 Animated Glow Card — incident-014

A visually striking **hover-activated animated card** inspired by Cars, featuring a glowing conic-gradient border that comes alive on interaction.

This project is part of the **_Incident Series_** — focused on experimenting with advanced CSS properties, animation systems, and interactive visual effects.

---

## 🚀 Project Overview

Incident-014 explores how modern CSS features can be used to create dynamic, premium-looking UI components without JavaScript.

The card includes:

- 🔥 Animated conic-gradient border
- 🎨 Custom font integration
- ✨ Hover-triggered glow effects
- 💡 Smooth animation control using CSS variables
- 🎬 Clean cinematic dark theme

The main goal of this incident is to understand **CSS Houdini properties, gradient borders, and hover-based animation control**.

---

## 📌 Core Concepts Implemented

### 1️⃣ CSS Houdini `@property`

A custom CSS variable is defined to allow smooth animation of rotation values.

This enables:

- Animating gradient angles
- Controlled rotation behavior
- Advanced CSS animation techniques

---

### 2️⃣ Conic Gradient Border Trick

The card uses layered backgrounds:

- Inner solid background (content area)
- Outer animated conic-gradient border

This creates a glowing animated frame effect without extra elements.

---

### 3️⃣ Hover-Controlled Animation State

The animation is paused by default.

On hover:

- Animation starts running
- Glow shadow increases
- Text color changes
- Text shadow intensifies

This demonstrates **interaction-based animation control** purely with CSS.

---

### 4️⃣ Custom Font Integration

A themed font is loaded using `@font-face`.

This enhances:

- Visual identity
- Branding style
- Thematic consistency

---

### 5️⃣ Smooth Visual Feedback

Transitions ensure:

- Soft glow expansion
- Text highlight effect
- Border animation continuity

This improves perceived responsiveness.
