## 📌 Core CSS & SCSS Concepts Implemented

This project applies and explains several foundational web styling techniques:

### 🎨 CSS Concepts

- **Box Model Fundamentals** — padding, border, margin, and element sizing
- **Layout Techniques**:
  - **Flexbox** for alignment and spacing
  - **CSS Grid** for advanced UI layout
- **Responsive Design Principles** using media queries
- **Typography & Visual Styling** — effective use of fonts, color, spacing
- **Positioning** — static, relative, absolute positioning for layout control
- **Transitions & Effects** for smooth UI feedback

### 🔧 SCSS Features

- **Variables** — centralize colors, font sizes, spacing units
- **Nesting** — hierarchical CSS structure using SCSS syntax
- **Partials & Imports** — split styles into manageable modules
- **Mixins** — reusable groups of style rules
- **Extend/Inheritance** — share common properties across selectors
- **Functions & Operations** — dynamic styling and calculations
- **Modular Architecture** — improved readability and maintainability

These concepts are researched and implemented within the code itself, and each core concept is explained with comments to strengthen understanding.
