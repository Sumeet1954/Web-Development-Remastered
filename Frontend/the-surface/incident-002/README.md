A frontend web project celebrating the Indian festival **Makar Sankranti**, built as part of the **Web Development Remastered** series.  
This project focuses on festive UI design, clean layout structuring, and responsive visuals using core frontend technologies.

---

## 🚀 Project Overview

**Makar Sankranti – The Festive Surface** is a static frontend project designed to visually represent the joy, harvest spirit, and cultural essence of the festival.  
The goal was to create a clean, engaging, and culturally inspired interface while maintaining readable and well-structured code.

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Git & GitHub

---

## ✨ Key Features

- Festive hero section with layered visual elements
- Clean and elegant typography
- Traditional sweets showcase section
- Responsive layout across devices
- Beginner-friendly and maintainable code structure

---

## ⚙️ Development Workflow

1. Planned the festive theme and layout
2. Structured the content using semantic HTML
3. Styled the interface with CSS and custom fonts
4. Organized visual elements for better aesthetics
5. Refactored code for clarity and maintainability
