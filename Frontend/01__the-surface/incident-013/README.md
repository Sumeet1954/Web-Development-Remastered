A frontend UI project built as part of the **Web Development Remastered** series.  
This project focuses on recreating a modern, real-world landing page interface using **HTML and CSS**, with special attention to **typography, layout, and responsive design**.

---

## 🚀 Project Overview

**Incident-013** is a frontend surface-level project inspired by modern design platforms like **Dribbble**.  
The goal of this project was to practice **clean UI structuring**, **CSS layout techniques**, **typography systems**, and **mobile responsiveness**, while keeping the code readable and beginner-friendly.

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- Custom Web Fonts
- Remix Icon
- Git & GitHub

---

## ✨ Key Features

- Clean navigation bar with responsive behavior
- Hero section with strong visual hierarchy
- Video-based visual layout using `object-fit`
- Search UI with interactive hover effects
- Fully responsive layout for mobile screens
- Custom typography using web-hosted fonts

---

## 📌 Core CSS Concepts Implemented & Analyzed

This project intentionally applies several **core CSS fundamentals**:

### 🎨 1. Box Model & Spacing

- Consistent use of `padding`, `margin`, and `box-sizing: border-box`
- Scalable spacing using **viewport units (`vw`, `vh`)**
- Rounded UI elements using `border-radius`
