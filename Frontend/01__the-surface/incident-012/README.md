## 📌 Core CSS & SCSS Concepts Implemented

This project applies and illustrates the following styling concepts:

### 🎨 CSS Concepts

- **Box Model** — proper control of margin, padding, and borders for spacing
- **Flexbox & Grid Layouts** — aligning and organizing layout sections
- **Responsive Design** — using **media queries** for mobile-friendly UI
- **Visual Styling** — effective use of color, spacing, and typography
- **Transitions & Interactions** — hover/focus effects for engaging UI

- **Nesting** — structured rules reflecting HTML hierarchy
- **Mixins** — reusable style blocks for consistency
- **Partials & Imports** — modular style breakdown for maintainability
