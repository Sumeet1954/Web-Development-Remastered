# ⚛️ Fuel Injection-003 — React State Flow & Component Communication

A React-based mini project focused on understanding **state lifting, data sharing between components, conditional rendering, and event-driven UI updates**.

This project is part of the **Fuel Injection Series**, where each build is designed to strengthen real-world frontend fundamentals through hands-on implementation.

---

## 🚀 Project Overview

Fuel Injection-003 is a small React application built to deeply understand how:

- State flows in a React application
- Parent and child components communicate
- UI re-renders when state changes
- Conditional rendering controls visual output
- Event handling drives application logic

Rather than focusing on design complexity, this project emphasizes **React architecture thinking**.

---

## 🛠️ Technologies Used

- **React (Functional Components)**
- **React Hooks (useState)**
- **JavaScript (ES6+)**
- **CSS3**
- **Vite / React Setup**

---

## ✨ Core Features

- State managed in a parent component
- State lifted and shared with child components
- Props used for controlled data flow
- Event handlers passed as props
- Conditional rendering based on state values
- Dynamic UI updates on interaction

---

## 📌 Concepts Implemented

### 1️⃣ State Management with Hooks

- `useState` used to manage application state
- State updates trigger automatic re-rendering
- UI reflects real-time state changes

This reinforces the idea that:

> UI in React is a function of state.

---

### 2️⃣ State Lifting (Lifting State Up)

- State moved to a common parent component
- Child components receive data via props
- Child interactions update parent state

This demonstrates **unidirectional data flow**, a core React principle.

---

### 3️⃣ Data Sharing via Props

- Data passed from parent → child
- Functions passed as props for event handling
- Controlled components pattern applied where necessary

This builds understanding of component communication patterns.

---

### 4️⃣ Conditional Rendering

- UI elements rendered based on state conditions
- Different outputs displayed depending on user interaction
- Logical rendering using `&&`, ternary operators, or conditional blocks

This helps in designing **dynamic user interfaces**.

---

### 5️⃣ Event Handling

- Click events trigger state updates
- Functions passed down to child components
- UI behavior directly tied to user interaction

This strengthens understanding of React’s event system.
